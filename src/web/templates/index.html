How It Works
Standard Analysis Process
  1. News Collection: Fetch latest financial news from multiple sources (Finnhub, Reddit, Yahoo Finance)
  2. AI Sentiment Analysis: Use advanced AI models (Ollama, DeepSeek, or OpenAI) for sentiment analysis
  3. Sentiment Scoring: Convert news sentiment into quantitative scores (-1 to +1)
  4. Signal Generation: Transform sentiment into actionable trading signals
  5. Trading Recommendations: Generate optimized options strategies with strike prices and expiry dates
Enhanced Analysis Process
